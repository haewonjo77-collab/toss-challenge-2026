# 참석자 보조 플로우 — 그리드 상호작용 개선 설계

날짜: 2026-07-06
대상: `/join/times` (TimeGrid) 드래그 선택, 단계 진행 표시, 강조 대비.

## 1. 드래그 선택

클릭 한 번 = 토글(기존 동작 유지), 드래그 = 여러 셀을 같은 값으로 일괄 적용.
`mousedown` 시점의 셀 상태 반전값을 "이번 드래그의 목표값"으로 고정해두고,
드래그 중 지나가는 모든 셀에 그 목표값을 그대로 적용한다(토글 반복이 아님) —
그래야 지그재그로 지나가도 깜빡이지 않고 한 방향으로만 칠해진다.

- `TimeGrid`의 `onToggle(day, slot)` prop을 `onSetUnavailable(day, slot, value)`로 교체.
  `JoinContext`의 `toggleUnavailable`도 `setUnavailable(key, value)`로 교체(명시적 설정).
- 클릭 한 번(드래그 없이 mousedown→mouseup)은 target = `!isUnavailable(...)`이므로
  결과적으로 토글과 동일 — 별도 클릭 핸들러 불필요, mousedown 하나로 통일.
- 터치: `touchstart`로 드래그 시작, `touchmove`에서 `document.elementFromPoint`로 손가락
  아래 셀을 찾아 같은 목표값 적용(셀에 `data-day`/`data-slot` 부여). 드래그 종료는
  `window`의 `mouseup`/`touchend`로 감지(그리드 밖에서 손을 떼도 확실히 종료).
- 실수로 누른 셀 취소: 다시 눌러 토글되므로 요구사항 4(별도 확인 팝업 없이 재클릭 취소)를
  그대로 만족.

## 2. 단계 진행 표시

- 상단에 점 인디케이터(●=현재/지난 단계, ○=예정 단계)를 단계 수만큼 렌더링.
- 부제목을 "이번 주 {전체 일수}일 중 {현재 단계 요일}"로 바꿔 전체 범위를 먼저 인지시킴.
- 마지막 단계가 아니면 다음 버튼 라벨에 다음 단계 요일을 덧붙임: "다음 (목·금)".
  마지막 단계는 기존대로 "제출하기".

## 3. 강조 대비 강화

- 기본 셀 보더를 `hairline-soft`→`hairline`으로 올려 그리드 자체의 셀 경계가 흰 배경에서도
  또렷이 보이게 함(선택 전/후 대비를 위해 "선 안 보이던" 문제부터 해결).
- 선택된 셀은 그대로 `surface-strong` 배경+보더로 완전히 채워진 블록 — 흰 배경(선 있음) vs
  진한 회색 블록의 명도 차이로 상태를 구분(색상 미사용 원칙 유지).
- 드래그 중 텍스트 선택/스크롤 간섭 방지: 그리드에 `user-select: none`, 셀에
  `touch-action: none`.
